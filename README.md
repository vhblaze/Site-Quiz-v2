# Site Quiz V2

Um **quiz interativo online** desenvolvido para aprendizado e prática de conceitos de desenvolvimento web. Este projeto é open source e construído para facilitar a criação, execução e gerenciamento de quizzes de forma simples e visualmente agradável.

---

## 🚀 Tecnologias Utilizadas

- **HTML5** – Estrutura básica do site
- **CSS3** – Estilização responsiva e moderna
- **JavaScript** – Funcionalidades interativas do quiz
- **Git & GitHub** – Controle de versão e colaboração open source

---

## 💻 Funcionalidades

- Adicionar perguntas e respostas de forma dinâmica
- Sistema de pontuação automático
- Feedback imediato para cada resposta
- Interface responsiva para desktop e mobile
- Fácil de expandir para novos quizzes
